# Lupa Fiscal web UI

Angular app for the search page. Run the commands from the repository root:

- Install: `npm --prefix web ci`
- Build: `npm --prefix web run build` (output in `web/dist`, served by the API on http://localhost:4401)
- Test: `npm --prefix web test`
- Dev server: `npm --prefix web start` (http://localhost:4400, proxies `/api` to the API on 4401)

The design reference is `DESIGN.md` at the repository root.
